## 2. Hasil Pengujian Empiris (Harness: `src/spikes/spike-gemini.ts`)

- Total 46 model flash/gemini ditemukan pada API key aktif.
- Model generasi lama (`gemini-2.5-flash`) telah didepresiasi upstream dan digantikan oleh generasi baru:

  - **TTS Preview**: `models/gemini-2.5-flash-preview-tts`.

- **Keputusan**: **GO**.
- Ekosistem Google Gen AI (`@google/genai`) terbukti sangat kapabel untuk menjadi motor penggerak Pipeline A (STT $\rightarrow$ LLM $\rightarrow$ TTS).
- `models/gemini-3.5-flash-lite` resmi ditetapkan sebagai konfigurasi `LLM_MODEL` default berkat TTFT ~1.0 detik.
