### Temuan F1 (Handshake & Enkripsi DAVE)
1. **Kegagalan pada `@discordjs/voice@0.18.0`**:
   - Paket `0.18.0` tidak menyertakan modul DAVE protocol.
   - Sesi voice gateway mengalami timeout dan abort (`connection state: signalling -> connecting -> signalling -> AbortError`), membuktikan Discord menolak koneksi voice yang tidak mampu melakukan negosiasi enkripsi DAVE.
2. **Keberhasilan pada `@discordjs/voice@0.19.2`**:
   - Setelah memperbarui dependensi ke `@discordjs/voice@0.19.2` yang mengintegrasikan `@snazzah/davey@^0.1.9`, handshake enkripsi DAVE E2EE langsung berhasil:
   ```text

   [Spike DAVE] Node.js version: v24.12.0
   [Spike DAVE] Bot is present in 1 guild(s): [ 'Kekaisaran Lamburgh (1527705094051725424)' ]
   [Spike DAVE] Joining Save roomm (1528772217524191242) via prefix command...
   [Spike DAVE] Connection state: signalling -> connecting
   [Spike DAVE] Connection state: connecting -> connecting
   [Spike DAVE] Connection state: connecting -> connecting
   [Spike DAVE] Connection state: connecting -> connecting
   [Spike DAVE] Connection state: connecting -> ready
   [Spike DAVE] Handshake SUCCESS in 1165ms! (TC-01 Passed)
   ```

   - **Hasil TC-01**: **LULUS** (Status mencapai `ready` dalam 1,16 detik tanpa close code `4017`).

### Temuan F2 (Receiver Stream & Decoding Audio)
1. Paket audio terenkripsi yang dialirkan pengguna diterima melalui `connection.receiver.subscribe(userId)`.
2. Untuk mendekompresi paket Opus ke PCM tanpa ketergantungan compiler C++ di Windows, dipasang library WebAssembly murni **`opusscript@0.1.1`** (sesuai spesifikasi monorepo AIRI).
3. Audio ucapan pengguna berhasil ditangkap dan disimpan:
   - **Durasi**: `5.72 detik`
   - **Ukuran File**: `549.164 bytes (~536 KB)`
   - **Format**: WAV PCM 48kHz Mono 16-bit

   ```text
   [Spike DAVE] Saved WAV sample to: G:\bot-ai\debug_audio\spike-dave-1792532723045.wav (5.72s, 549164 bytes)
   ```
   - **Hasil TC-02**: **LULUS** (File WAV tersimpan utuh dan dapat diputar).
